# Privacy Policy

Last updated: 2026-07-16

This Privacy Policy explains what data the Jimmy bot and dashboard may collect, how it is used, and how it is stored.

## Information Collected

When the bot is used in Discord servers, it may process:

- Discord user IDs, usernames, display names, and avatars
- Message content sent in the target server
- Message metadata such as channel, timestamp, and author ID
- Server and member metadata such as roles, join dates, and presence status when available
- Moderation activity such as bans and message purges

If the dashboard is opened, it may display recent messages, member lists, and server statistics for the configured server.

## How Information Is Used

Collected information is used to:

- Provide bot commands and dashboard features
- Display server statistics and recent activity
- Support moderation actions
- Detect spam, scams, or repeated abusive content
- Log moderation actions for server administration

## Data Retention

The bot may keep local logs, cache data, or stored statistics needed to run commands and the dashboard. Data may remain in process memory, local files, or log files on the host system until it is cleared or the bot is restarted, unless a feature explicitly stores it longer.

## Sharing of Information

Information is not sold. Data may be visible to server staff through the dashboard or moderation logs. Data may also be processed by Discord as part of normal bot operation.

## Security

Reasonable technical measures should be used to protect the bot host and any stored data. No system can be guaranteed to be completely secure.

## Children's Privacy

This bot and dashboard are not intended for children under 13, and users should only use them in accordance with Discord's age requirements and local law.

## Changes To This Policy

This policy may be updated from time to time. Continued use of the bot or dashboard after changes are posted means you accept the updated policy.

## Contact

If you have privacy questions, contact the server administrator or bot owner.
